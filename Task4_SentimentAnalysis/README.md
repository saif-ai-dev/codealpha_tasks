# Task 4: Sentiment Analysis

## Objective
Analyze Amazon Fine Food Reviews to classify customer sentiment as Positive, Negative, or Neutral using NLP techniques.

## Dataset
Amazon Fine Food Reviews (Kaggle) — 568,454 reviews, sampled 5,000 for analysis.

## Approach
1. Loaded and cleaned review text data
2. Applied VADER Sentiment Analysis to classify each review
3. Visualized sentiment distribution with a bar chart
4. Generated word clouds for positive and negative reviews

## Key Insights
- Total reviews analyzed: 5,000
- Positive: 4,418 (88.4%)
- Negative: 481 (9.6%)
- Neutral: 101 (2.0%)
- Common positive words: taste, delicious, love, good, flavor
- Common negative words: disappointed, bad, product, taste

## Tools Used
Python, Pandas, VADER Sentiment, Matplotlib, Seaborn, WordCloud
