# Task 3: Data Visualization

## Objective
Transform raw data into visual formats (charts, graphs) to reveal insights and support data storytelling.

## Dataset
2019 World Happiness Report data (2019.csv)

## Visualizations Created
- Top 10 happiest and bottom 10 least happy countries
- Correlation heatmap between happiness factors
- GDP vs Score, Freedom vs Score, Generosity vs Score scatter plots
- Score distribution and pairplot of key factors

## Tools Used
Python, Pandas, Matplotlib, Seaborn
