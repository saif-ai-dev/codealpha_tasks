# Task 2: Exploratory Data Analysis (EDA)

## Objective
Explore dataset structure, identify trends, patterns, and anomalies, and validate assumptions using statistics and visualization.

## Dataset
Superstore Sales dataset (superstore_sales.csv)

## Approach
1. Explored data structure, variables, and data types
2. Identified trends and patterns in sales and profit
3. Detected data quality issues
4. Generated an automated profiling report

## Key Files
- notebooks/eda_retail_sales_analysis.ipynb - main analysis notebook
- reports/superstore_profiling_report.html - automated data profiling report
- images/ - key visualizations (monthly sales trend, category sales/profit, profit distribution)

## Tools Used
Python, Pandas, Matplotlib, Seaborn
